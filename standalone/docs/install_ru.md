# Установка: ПК + телефон (Telegram) — полная инструкция

> ⚠️ Это reference scaffold: реальные рыночные данные, демо-деньги, **ни один ордер никуда не отправляется**. Подтверждение с телефона — это подтверждение *метаданных допуска* в пайплайне, а не команда брокеру.

---

## Вариант A: только MetaTrader 5 — без Python и установок ⭐

Вся логика вшита в эксперта `mql5/CriticalConsensusStandalone.mq5`: агенты, certainty gate, два режима и Telegram — прямо внутри MT5. Python не нужен.

1. Создай бота через **@BotFather** (`/newbot`) — получишь **токен**.
2. В MT5: **Файл → Открыть каталог данных** → скопируй `CriticalConsensusStandalone.mq5` в папку `MQL5\Experts\`.
3. В MT5: **Сервис → Настройки → Советники** → поставь галочку «Разрешить WebRequest для URL» и добавь: `https://api.telegram.org`
4. В Навигаторе открой советника (MetaEditor, клавиша F7 — компиляция), затем перетащи на график **EURUSD, M15**.
5. В настройках советника: вставь **токен**, выбери **WorkMode** (confirmation — с подтверждением на телефоне / autonomous — без вопросов, кап 0.05 лота). ChatID оставь пустым.
6. Напиши боту `/start` в Telegram один раз — chat_id подхватится автоматически.

Дальше советник сам: 5 агентов голосуют по реальным котировкам (тренд, RSI, волатильность, свечи, сессия), все «ЗА» → сделка (в confirmation — карточка на телефон с кнопками; в autonomous — сразу, но не больше 0.05 лота и 3 сделок в день). Работает **только на демо-счёте**: на реальном советник отказывается торговать.

> Советник написан, но не компилировался (здесь нет MetaEditor). Если MetaEditor покажет ошибку при F7 — пришли текст ошибки, поправлю.

## Самый простой путь Python-версии (30 секунд)

1. Установи Python с python.org (галочка **"Add python.exe to PATH"**!).
2. Открой папку проекта и **дважды кликни `start.bat`**.
3. Первый запуск сам установит зависимости; вставь токен бота от @BotFather; напиши боту `/start` в Telegram — chat_id определится сам.
4. Выбери режим: `[1]` confirmation (с подтверждением на телефоне) или `[2]` autonomous (без вопросов, только demo).
5. Готово — демо торгует на реальных данных EUR/USD демо-деньгами. Всё запоминается: следующий запуск — просто `start.bat`.

Autonomous сразу: `start_autonomous.bat`. Сбросить настройки: `python scripts\run.py --reconfigure`.

Ниже — подробности каждого шага.

## Часть 1. Компьютер (Windows)

### Шаг 1. Python

1. Скачай Python 3.12: https://www.python.org/downloads/
2. При установке **обязательно** поставь галочку **"Add python.exe to PATH"**.
3. Проверь: открой командную строку (Win+R → `cmd`) и введи:
   ```
   python --version
   ```
   Должно быть `Python 3.12.x`.

### Шаг 2. Код проекта

Вариант А (с git):
```
git clone https://github.com/paulafanasyev/mt5-critical-consensus.git
cd mt5-critical-consensus
```
Вариант Б (без git): скачай zip с GitHub (Code → Download ZIP), распакуй, открой cmd в распакованной папке.

### Шаг 3. Зависимости

```
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

### Шаг 4. Проверка, что всё работает

```
python -m pytest -q
```
Ожидается `176 passed` (один warning от starlette — норма).

### Шаг 5. Создай Telegram-бота (2 минуты)

1. В Telegram найди **@BotFather** → команда `/newbot`.
2. Придумай имя и username бота (username должен кончаться на `bot`).
3. BotFather выдаст **токен** вида `1234567890:AAEhBOweik6ad9r_QXMENQjcrGbqCr5G-p4` — сохрани его.
4. Теперь узнай свой **chat_id**: напиши своему боту любое сообщение (например `/start`), затем открой в браузере:
   ```
   https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates
   ```
   В ответе найди `"chat":{"id":123456789,...}` — это твой **chat_id**.

### Шаг 6. Переменные окружения

В cmd (или сохрани в `.env` и используй как шаблон `env.example`):
```
set TELEGRAM_BOT_TOKEN=1234567890:AAEhBOweik6ad9r_QXMENQjcrGbqCr5G-p4
set TELEGRAM_CHAT_ID=123456789
```
Для постоянной работы задай их через «Переменные среды Windows» (Win → "Изменение системных переменных среды").

### Шаг 7. Запуск демо на реальных данных

**Confirmation-режим (каждая сделка — через твоё подтверждение):**
```
python scripts/demo_real_data.py --trades 3 --telegram
```
Тебе в Telegram придёт карточка: реальная цена EUR/USD, направление, SL/TP, риск в долларах — и кнопки **✅ Approve / ❌ Reject**. Нажимаешь с телефона → сделка подтверждается в пайплайне.

**Autonomous-режим (без вопросов, только demo, потолок 0.05 лота):**
```
python scripts/demo_real_data.py --trades 3 --autonomous
```

**Без Telegram (консоль):**
```
python scripts/demo_real_data.py --trades 1
```

### Шаг 8 (опционально). API-сервис

```
set MT5_BRIDGE_TOKEN=какой-нибудь-длинный-секрет-минимум-24-символа
python -m uvicorn critical_consensus.api:app --host 127.0.0.1 --port 8000
```
Проверка: `curl http://127.0.0.1:8000/health`

## Часть 2. Телефон (iPhone / Android)

1. **Telegram** — App Store / Google Play, войди в аккаунт, который создавал бота.
2. Открой чат со своим ботом, нажми `/start`. Теперь карточки подтверждений будут приходить сюда.
3. **MetaTrader 5** (App Store / Google Play) — установи, открой **демо-счёт** (Menu → New Account → Demo), чтобы видеть котировки и демо-баланс.
4. Подтверждая карточку в Telegram, ты подтверждаешь решение пайплайна на реальных данных; в MT5 при желании можно руками открыть ту же сделку на демо-счёте — каркас сам ничего в MT5 не отправляет.

## Часть 3. Вариант "всегда работает": VPS

1. Возьми Windows VPS (Any European host, от ~$10/мес).
2. Подключись по RDP (iPhone: приложение **Windows App** / Microsoft Remote Desktop).
3. Повтори на VPS шаги 1–7. Теперь демо работает 24/7, а телефон — только пульт.

## Безопасность

- Никогда не публикуй токен бота. Если утёк — отзови через BotFather `/revoke`.
- API слушает только `127.0.0.1` — не открывай порты наружу.
- Autonomous-режим: двойной opt-in, только demo, потолок размера. В каркасе по-прежнему ни один ордер не отправляется.
