# Стратегия роя агентов (демо, MetaTrader 5)

Один процесс `scripts/agent_swarm.py`, 45 агентов, 12 схем. Каждый агент — отдельный
набор правил со своим magic-номером (`8180000 + crc32(имя) % 5000`), поэтому состав роя
можно переставлять, не теряя привязку открытых позиций.

## Инструменты

| Группа | Инструменты | Статус |
|---|---|---|
| FX | EURUSD, GBPUSD, USDJPY, AUDUSD, USDCHF, USDCAD, NZDUSD | торгуются |
| металлы | XAUUSD, XAGUSD | торгуются (наблюдение/эксперимент) |
| индексы | US500, US30, UK100, JPN225, USTEC | **запрещены демо-сервером MetaQuotes** (trade_mode = DISABLED) |
| акции США | ~11 000 символов | доступны, схем пока нет |

## Схемы

### Тренд и импульс

| Схема | Правило входа | Выход |
|---|---|---|
| `h1_ema` (ema-xau/xag, sil-ema) | H1 EMA50 против EMA200 и цена по нужную сторону EMA200 | стоп 2×ATR, цель 2R |
| `momentum_buy` (mom-*, sil-mom) | аптренд: EMA50 > EMA200, цена выше EMA50, последняя H1 растёт | стоп 2×ATR, цель 2R |
| `dip_buy` (dip-*, sil-dip) | падение ≥ 2.5 ATR за 6 часов и разворотная свеча (минимум не обновлён) | стоп 2×ATR, цель 2R |
| `weekly_momentum` (wm-*, sil-week) | недельный тренд по EMA200 дневных баров | закрытие по смене недельного тренда |

### Календарь

| Схема | Правило | Окно |
|---|---|---|
| `monday_long` (mon-long-*) | покупка в понедельник 00:00 серверного | выход в 21:00 |
| `monday_gap_fill` (gap-*) | гэп > 0.1% против пятничного закрытия → закрытие гэпа | понедельник, выход 21:00 |
| `monday_gap_continue` (gold-gap) | гэп → продолжение движения | понедельник, выход 21:00 |
| `first_hour` (fh-*) | вход в 22:00 UTC (открытие Азии) на час | выход 22:55 |
| `session_long` (us500-*) | лонг на американской сессии | не работает: инструмент запрещён |
| `turn_of_month` (x-tom-xau) | конец месяца | раз в месяц |

## Управление риском

| Правило | Значение |
|---|---|
| Дневной стоп | −1% от equity на начало дня UTC → всё закрыть, пауза до следующих суток |
| Общий стоп | −3% от 100 000 → полная остановка до ручного сброса |
| Долларовый стоп | `max($10, 40% риска позиции)` на каждую позицию |
| Churn guard | максимум **3 входа на символ в час** |
| Пауза после стопа | 30 минут на символ |
| Пауза после ручного закрытия | 5 минут на символ |
| Лимиты на символ | золото 0.10, серебро 0.10, FX 0.07, индексы 0.30 |
| Стоп по позиции | 2–3×ATR, цель 2R |
| Безубыток | при пике прибыли +$12 стоп в точку входа |
| Продажа на пике | свеча-отказ на экстремуме последних 4 баров → закрытие в плюсе |
| Откат прибыли | отдал $5 или 40% пика (что больше) → закрытие |
| Долив к прибыли | +15 / +30 / +50 / +75 → +50% объёма (в пределах лимита) |
| Один вход на агента | агент держит не более одной позиции, повторный вход только после закрытия |

## Инфраструктура

```
agent_swarm.py        торгует, управляет позициями          (цикл 20 с)
swarm_supervisor.py   стопы, сироты, чужие позиции, тормоз   (цикл 60 с)
keepalive.ps1         поднимает упавшее                       (каждую минуту, Task Scheduler)
real_mirror.py        копирует прибыльные демо-сделки на реальный счёт (по протоколу)
promotion_gate.py     ворота допуска схемы к реальным деньгам
terminal_inventory.py инвентаризация любого MT5-терминала
```

Windows-задачи: `DSH-Trading-KeepAlive`, `DSH-Trading-AtLogon`, `DSH-Trading-DailyReport`.

## Допуск к реальным деньгам

Схема идёт на реальный счёт только после:

1. ≥ 100 закрытых сделок на демо;
2. матожидания > 0 после реального спреда;
3. 95% бутстрап-интервала выше нуля;
4. просадки ≤ 15% выделенного капитала;
5. двухнедельной «тени» на реальной площадке без ордеров.

Полный протокол: `docs/studies/demo_to_real_protocol.md`.

## Честное ограничение

Ни одна схема пока не прошла ворота Stage 1: у них меньше 100 сделок. Доход не обещан;
задача системы — измерять, отсеивать и масштабировать только то, что показывает
положительное ожидание после издержек.
