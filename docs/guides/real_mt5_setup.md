# Реальный счёт на MT5: как это будет устроено

Требование оператора: реальный счёт — тоже MT5, отдельно от демо-лаборатории.
Ниже — точная схема и что нужно сделать руками (пароль мне присылать не нужно).

## Почему отдельный терминал, а не тот же

Один терминал MetaTrader 5 может быть залогинен только в один счёт одновременно. Если
переключить текущий терминал на реальный, демо-лаборатория остановится. Поэтому:

```
C:\Program Files\MetaTrader 5\      → демо 114929502 (лаборатория, рой 30 агентов)
C:\mt5-real\terminal64.exe          → реальный счёт (новый раннер, риск 0.1–0.25%)
```

Оба работают одновременно, у каждого своя папка данных, свои логи и свои ордера.

## Что сделать (около 15 минут)

1. **Открыть реальный счёт у брокера** с MT5. Минимальный депозит — от $100–200 у
   большинства; для первого теста хватит $200.
2. **Установить второй терминал** отдельно от текущего:
   - скачать MT5 у брокера (или с metatrader5.com);
   - при установке выбрать папку **C:\mt5-real**;
   - в свойствах ярлыка добавить `/portable`, чтобы данные лежали внутри этой папки.
3. **Войти в реальный счёт** в этом терминале: сервер, логин, пароль трейдера.
   Пароль остаётся у тебя — я работаю через уже залогиненную сессию.
4. **Оставить терминал запущенным** и сказать мне: «реальный счёт готов».
5. Я запускаю проверку:

```
python scripts/real_account_check.py --path "C:\mt5-real\terminal64.exe"
```

Она покажет логин, сервер, режим (REAL/DEMO), баланс и плечо — и откажется идти дальше,
если это не реальный счёт.

## Что будет запущено после проверки

| Параметр | Значение |
|---|---|
| Риск на сделку | **0.10%** (первый месяц), не больше 0.25% |
| Дневной стоп | **−0.5%** баланса → всё закрыть до следующего дня |
| Стоп схемы | −3% баланса → схема выключается |
| Позиции | одна на символ, без усреднения убытка |
| Выходы | безубыток на пике, откат 35% → закрытие, долив только на прибыли |
| Инструменты | сначала **только те схемы, что прошли Stage 1** |

## Правило допуска (из протокола)

Реальная торговля включается **не «когда хочется»**, а когда схема на демо:

- набрала **≥100 закрытых сделок**;
- имеет матожидание > 0 **после реального спреда**;
- имеет 95% интервал выше нуля;
- просадка ≤ 15% выделенного капитала.

Сейчас ворота не прошла ни одна схема (у них 1–6 сделок). Поэтому предлагаю:

1. Пока демо-лаборатория набирает статистику — **добавить M15-агентов** (в 4 раза больше
   сигналов), чтобы ворота быстрее наполнились.
2. Реальный счёт открыть **параллельно** и прогнать на нём Stage 2 (тень) на тех схемах,
   которые уже близки к воротам.

## Чего этот план не даёт

Демо не воспроизводит реальное исполнение: спред в моменте, слиппедж, задержку,
проскальзывание на стопах. Поэтому Stage 2 (тень на реальной площадке) обязателен — он и
показывает, сколько «съест» реальный рынок.
